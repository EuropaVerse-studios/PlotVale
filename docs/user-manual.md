# PlotVale user manual

> The app interface is bilingual (English/Italian): switch languages from the
> settings menu. This manual is in English; the in-app strings live in `locales/`.

## Your first 5 minutes

1. **Create a project**: File → New project. It starts with a "Manuscript" folder,
   an example scene, "Research", and "Trash".
2. **Write**: click a scene in the left-hand binder and write in the center.
   You can use Markdown formatting: `**bold**`, `*italic*`, `# Heading`.
3. **Organize**: right-click an item to create scenes, folders, and notes,
   move them around, or send them to the trash.
4. **Save**: everything autosaves after a few seconds; File → Save saves immediately.

## Key concepts

- **Scene**: a chunk of text (a chapter can hold several scenes).
- **Corkboard**: the "Corkboard" tab shows scenes as cards you can reorder.
- **Inspector**: the right-hand panel — synopsis, status (draft/revised/final),
  keywords for each item.
- **Snapshot**: a photo of a scene before a brave revision; compare and restore it anytime.
- **Annotation**: write `[[note: revise this]]` in the text — it will not be exported.
- **Export**: File → Export, pick a profile and a format (DOCX for your editor,
  EPUB for ebooks, PDF/HTML for friends to read).

## Your files are yours

The project is a single `.plotvale` file, but inside there are only text files.
With "Save as" you can also save it as a **folder** (handy for Git and backups).
No accounts, no mandatory cloud, no subscriptions.
