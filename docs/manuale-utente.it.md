# Guida rapida a PlotVale

## I primi 5 minuti

1. **Crea un progetto**: File → Nuovo progetto. Nasce con una cartella "Manoscritto",
   una scena d'esempio, "Ricerca" e "Cestino".
2. **Scrivi**: clicca una scena nella struttura a sinistra e scrivi al centro.
   Puoi usare la formattazione Markdown: `**grassetto**`, `*corsivo*`, `# Titolo`.
3. **Organizza**: tasto destro su un elemento per creare scene, cartelle e note,
   spostarle, metterle nel cestino.
4. **Salva**: tutto si salva da solo dopo qualche secondo; File → Salva per salvare subito.

## Concetti chiave

- **Scena**: un pezzo di testo (un capitolo può contenere più scene).
- **Cartellone**: la scheda "Cartellone" mostra le scene come biglietti da riordinare.
- **Scheda (inspector)**: il pannello a destra — sinossi, stato (bozza/rivisto/finale),
  parole chiave per ogni elemento.
- **Snapshot**: fotografia di una scena prima di una revisione coraggiosa; la puoi
  confrontare e ripristinare quando vuoi.
- **Annotazione**: scrivi `[[nota: da rivedere]]` nel testo: non verrà esportata.
- **Esporta**: File → Esporta, scegli profilo e formato (DOCX per l'editor,
  EPUB per l'ebook, PDF/HTML per far leggere agli amici).

## I tuoi file sono tuoi

Il progetto è un unico file `.plotvale`, ma dentro ci sono solo file di testo.
Con "Salva con nome" puoi anche salvarlo come **cartella** (comoda per Git e backup).
Niente account, niente cloud obbligatorio, niente abbonamenti.
