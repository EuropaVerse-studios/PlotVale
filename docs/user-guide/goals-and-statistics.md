# Goals and statistics

PlotVale can hold you to a writing target, and can tell you what you have actually
written. Both live in the *Project* menu: **Goals…** and **Statistics…**.

## Writing goals

Open **Goals…** to enable and set two independent targets:

| Goal | Meaning |
|---|---|
| **Daily goal (words)** | How many words you intend to write today. |
| **Project goal (words)** | The target size of the finished manuscript. |

The window then shows **Words written today** and a **Progress** bar, so the answer to
"am I done for today?" is one glance away. If nothing is enabled, it says so plainly
instead of showing a meaningless zero.

The new-project wizard offers ready-made daily targets: **500**, **1000**, **1667** (the
NaNoWriMo pace of 50,000 words in a month), and **2000** words, plus *None*.

```{note}
Word counting is identical in the goals, the statistics, and the editor's status bar: one
shared function, so the numbers can never disagree with each other.
```

## Statistics

Open **Statistics…** for a snapshot of the whole project:

- **Total words**
- **Text documents** — how many items actually contain text
- **Characters (no spaces)**
- **Paragraphs**
- **Words per chapter** — a breakdown of the manuscript, chapter by chapter

The chapter breakdown is the honest one: it uses the same chapter folders you see in the
[binder](binder.md), so if a chapter looks small, the binder shows you exactly which
scenes are missing.
