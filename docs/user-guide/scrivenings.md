# Continuous editing (scrivenings)

Writing a chapter as separate scenes is good for structure, but reading it as separate
scenes is not how a reader will experience it. **Scrivenings** mode shows a whole folder's
text as one continuous flow you can edit in place.

Turn it on from *View → Continuous editing (scrivenings)*, then **select a container** —
the Manuscript root, a chapter folder, or a research folder — in the
[binder](binder.md).

## What it does

- Every text-bearing item inside the selection appears **in binder order**, one after
  another, inside a single scroll area.
- Each boundary is marked by a small bar with the item's title, which you can click to
  jump to that item as a normal document. A separator follows each one.
- Each block stays independently editable: PlotVale still knows which scene a paragraph
  belongs to, and word counts and goals stay attached to it.

```{note}
Scrivenings needs a **container** to be selected. Turn it on while a single scene is
selected and nothing changes — there is no flow to build. The setting stays on until you
turn it off.
```

## When to use it

- Reading a chapter end to end for rhythm and repetition.
- Fixing transitions between scenes.
- Checking a chapter's pace before sending it to a beta reader.

## When not to use it

- Reordering scenes: use the binder or the [corkboard](corkboard.md), where each scene is
  a separate card.
- Per-scene metadata: use the [inspector](inspector.md).

```{note}
Scrivenings changes the *view*, not the model. Your project on disk is still one Markdown
file per scene: nothing is merged, and the
[format specification](../format-spec.md) is unaffected.
```
