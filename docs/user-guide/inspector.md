# The inspector

The inspector is the right-hand panel. It shows the metadata of the item selected in the
binder — everything about a scene that is not the scene's text.

## For every item

| Field | Notes |
|---|---|
| **Title** | The same name shown in the binder. |
| **Kind** | Scene, note, folder, research item, character, location… |
| **Status** | *To do*, *Draft*, *Revised*, *Final*. |
| **Label** | A free tag for grouping your own way. |
| **Synopsis** | One paragraph describing the scene. Shown on the [corkboard](corkboard.md). |
| **Keywords** | A comma-separated list, searchable across the project. |
| **Include in export** | Uncheck it to keep an item out of the manuscript. |
| **Document words** | The word count of the text in this item. |

The **status** is drawn as a coloured dot in the binder, so you can see the state of a
chapter without opening it:

| Status | Dot |
|---|---|
| To do | ○ grey |
| Draft | ● coral |
| Revised | ● light blue |
| Final | ● green |

## Snapshots

The inspector lists the item's [snapshots](snapshots.md) and lets you take a new one,
compare one against the current text, restore an old one, or delete one.

## Character and location sheets

Two kinds of item hold structured fields instead of a synopsis:

**Character sheet**

- Name
- Role in the story
- Description
- What they want
- Conflict
- Guided questions (optional): looks and manner, past in a few lines, their greatest
  fear, what they really want
- Sensory details
- Notes

A **location sheet** uses the same idea for places: name, description, sensory details,
and notes.

Sheets are never exported: they are scaffolding for you, not part of the manuscript. You
can prove that by exporting to any format — sheets stay out.

## Custom fields

In *View → Expert mode*, additional **custom fields** appear in the inspector, along with
the other advanced options. They are stored with the project and follow the
[format specification](../format-spec.md).
